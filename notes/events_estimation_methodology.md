# `events.csv` — Estimation Methodology

How every value in `data/raw/events/events.csv` was obtained, which values are
assumed, what each assumption rests on, and how `confidence` is computed.

Generated by `src/data/fetch_events.py`. **95 events × 22 columns**,
2017-01-01 → 2017-06-30, 4 venues. Full data dictionary:
`data/raw/events/README.md`. Machine-readable run summary:
`data/raw/events/events_meta.json`.

---

## 1. Four fields, resolved independently

Each field takes the **first source that has it**. Nothing here estimates a
**date** — all 95 dates come from a source.

| Field | Priority chain | Observed | Assumed |
|---|---|---|---|
| `start_time` | `espn` → `venue_detail_page` → `venue_site` → **`venue_convention`** | 79 | **16** |
| `expected_attendance` | `billboard_boxscore` → `espn` → **`default`** | 41 | **54** |
| `end_time` | *(no chain — always derived)* | 0 | **95** |
| `duration_min` | *(no chain — always from config)* | 0 | **95** |

### Formulas

```
end_time     = start_time + events.defaults[type].duration_min
start_time   = date + events.defaults[type].start            # only if assumed
attendance   = events.defaults[type].attendance              # only if assumed
```

Every row's `assumed_from` column names the exact config keys and values it
used, e.g.

```
start_time<-events.defaults.amphitheater_concert.start(19:00);
end_time<-events.defaults.amphitheater_concert.duration_min(180);
expected_attendance<-events.defaults.amphitheater_concert.attendance(18000)
```

## 2. What each `time_source` is backed by (measured 2026-09-02)

| `time_source` | n | Evidence |
|---|---|---|
| `espn` | 37 | **37/37 carry a real UTC kickoff, 0 placeholders.** Local times spread 13:00 ×2, 13:25 ×1, 17:30 ×1, 18:00 ×1, 19:00 ×8, 19:30 ×23, 20:00 ×1 — the shape of a real schedule |
| `venue_detail_page` | 40 | Page prints it literally: `Event Times · Friday, March 17, 2017 · 7:00 PM`. The riskier fallback path in `parse_sap_detail` fired on **3 pages, all outside the study period** |
| `venue_site` | 2 | Club front page, 2017-04-22: "Home Fri, Apr 21 **7:00PM** · Home Sun, Apr 23 **3:00PM**" |
| `venue_convention` | **16** | **Nothing.** `events.defaults[type].start` |

**Why Shoreline's published time is discarded.** Its JSON-LD carries a
`startDate`, but **all 127 blocks read `19:00`–`23:00` with a `+02:00` offset** —
impossible for California, identical for daytime festivals and evening concerts.
A WordPress plugin constant, not per-event data. Only the date is taken. Its
per-event pages were then checked for a real time: **4 pages fetched, zero time
patterns and zero "Doors" strings** — there is no cheaper source to try.

## 3. What each `attendance_kind` means

| `attendance_kind` | n | Meaning |
|---|---|---|
| `boxscore_observed` | 4 | **Strongest.** Real reported gate, Billboard Boxscore |
| `announced_observed` | 11 | League-announced, **varying** figure |
| `announced_sellout_at_capacity` | 26 | League-announced but **right-censored** at capacity |
| `type_default_estimate` | 54 | **Assumed** — `events.defaults[type].attendance` |

### The censoring, and what it is *not*

**No ESPN figure is a turnstile count.** US pro leagues report *tickets
sold/distributed*. The NFL row proves it: **70,178 at Levi's exceeds its 68,500
seating capacity** — you cannot seat more people than you have seats. All 37
overstate the crowd that actually travelled, by the no-show rate.

What separates the 26 is **right-censoring**, not measurement quality. The
measured shape at SAP Center:

| | |
|---|---|
| 10 non-sellout Sharks games | 17,386 / 17,387 / 17,402 / 17,424 / 17,442 / 17,459 / 17,479 / 17,488 / 17,497 / 17,515 — **10 distinct values** |
| 17 sellouts | **17,562 seventeen times** — a point mass exactly at the ceiling |
| Above the ceiling | **0** |

All 9 Avaya MLS matches sit at exactly 18,000. The figure means
**demand ≥ capacity**; the true value above it is unknowable, so **these 26 rows
carry no information about each other**.

**For the paper:** describe attendance as *announced (tickets sold)*, never
*measured crowd size*; state that 26 of 37 are censored at capacity; only the
4 Boxscore rows are reported gate counts.

## 4. The four bases behind every assumed number

| Tier | Basis | Types | Rows |
|---|---|---|---|
| **1** | **Measured** — a published figure for this team/act | `AHL` 4,412 · `stadium_concert` 50,072 | 24 |
| **2** | **= home venue capacity** (these fixtures sell out) | `NHL` 17,400 · `MLS` 18,000 · `NFL` 68,500 | ~0 in practice |
| **3** | **0.80 × capacity for that configuration** | `concert` 15,352 · `amphitheater_concert` 18,000 · `music_festival` 18,000 | 24 |
| **4** | **Judgement — no source, no formula** | `motorsport` 40,000 · `festival` 15,000 · `wrestling` 12,000 · `amateur_sport` 10,000 · `ice_show` 9,000 | **6** |

**Tier 1 detail.** AHL 4,412 = the Barracuda's published season average, 24th of
30 in the league (hockeydb) — but it is the **2015-16** figure; no 2016-17 number
is published anywhere reachable. `stadium_concert` 50,072 = the house U2 offered
and sold out at Levi's (Boxscore).

**Tier 2 detail.** Ratios: NHL 17,400/17,562 = 0.991, MLS 18,000/18,000 = 1.000,
NFL 68,500/68,500 = 1.000. Almost never used — 37/37 league rows carry ESPN's own
figure.

**Tier 3 detail.** Ratios: concert 15,352/19,190 = 0.800, amphitheater_concert
and music_festival 18,000/22,500 = 0.800. **The 0.80 factor is a convention, not
a source**, but it is now partly validated: the three Boxscore-measured Shoreline
shows load at 0.79 / 0.99 / 0.75, mean **0.84**, mean gate **18,502** against
this 18,000.

⚠ **Capacity is per configuration, not per venue.** SAP Center seats 17,562 for
hockey but **19,190 for a concert**; using the hockey number gave a concert
default of 14,000, ~9% low on 15 rows. Levi's is deliberately given **no**
concert capacity — a stadium concert has none that is stable (U2 offered 50,072
in 2017, the venue record is 80,058).

**Start times and durations are all Tier 4.** No source publishes them; every
value below is a convention.

## 5. `confidence` — the exact rule

```python
time_est   = time_source == "venue_convention"
att_est    = att_source not in ("espn", "billboard_boxscore")
confidence = "high" if not time_est and not att_est else \
             "low"  if     time_est and     att_est else "medium"
```

| start assumed? | attendance assumed? | `confidence` | n |
|---|---|---|---|
| no | no | **high** | 37 |
| no | yes | medium | 42 |
| yes | no | medium | 4 |
| yes | yes | **low** | 12 |

⚠ **`end_time` is deliberately excluded.** It is assumed on 100% of rows;
including it would make every row `low` and destroy the column. Read
`end_time_is_estimated` (always 1) for that.

⚠ **`medium` has two opposite causes**: 42 rows have a sourced time and a guessed
crowd; 4 rows have a measured crowd and a guessed time.

venues (Oracle Arena, AT&T Park) are 39–49 km out and excluded.

### Why each confidence value falls where it does

* **All 37 `high` rows are ESPN rows.** Only ESPN supplies an exact time *and* an
  announced crowd in one record. Three types: NHL, MLS, NFL.
* **`medium` from a guessed crowd (42)** — AHL, concert, wrestling, ice_show. The
  venue published the show time; nobody published the gate.
* **`medium` from a guessed time (4)** — U2 plus three Shoreline shows. Billboard
  published the gate; the calendar published only a date.
* **All 12 `low` rows are at Levi's or Shoreline.** Neither venue's calendar
  publishes times, and neither is covered by a league API.

### Duration assumptions (used on all 95 rows — the widest-reaching assumption)

| Minutes | Types | Rationale (convention, not a source) |
|---|---|---|
| 120 | MLS | 90 min + half-time + stoppage |
| 150 | NHL, AHL, ice_show | 3 periods + 2 intermissions |
| 180 | concert, wrestling, amateur_sport | support act + main |
| 195 | NFL | typical 3 h 15 min |
| 210 | motorsport, stadium_concert | includes pre-show |
| 360 | festival | daytime food expo, 11:00–17:00 |
| **660** | **music_festival** | **all-day, 12:00–23:00** |

`eval.event_phases.egress` is defined **relative to `end_time`**, so an error in
these durations shifts the whole egress window.

## 7. Reliability, in one block

```
date          95/95  sourced     never assumed
start_time    79/95  sourced     16 assumed  (4 Levi's + 12 Shoreline)
attendance    41/95  sourced     54 assumed  (24 Tier 1 · 24 Tier 3 · 6 Tier 4)
end_time       0/95  sourced     95 assumed  ← widest reach, weakest basis
venue coords   8/8   verified    OpenStreetMap, max delta 96 m
venue capacity 6/8   verified    Wikipedia infoboxes; per-configuration
```

**The single biggest weakness is `end_time`**: 95/95 rows rest on a convention I
chose, and the reported egress window is measured from it.
